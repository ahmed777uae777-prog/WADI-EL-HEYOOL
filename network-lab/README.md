# مختبر الشبكات الافتراضي

مختبر ثلاثي الأبعاد لدرس توصيل شبكة مختبر الحاسوب بالإنترنت — مدرسة وادي الحيول (1-12).

- **العب وحدك:** قيادة السيارة إلى المدرسة ثم تنفيذ مهمة التوصيل.
- **وضع الصف:** المعلم ينشئ غرفة برمز من 4 أرقام، والطلاب ينضمون بالرمز ويركبون في 3 سيارات.

ملف واحد: `index.html`. أي رفع إلى `main` يُنشر تلقائيًا على Vercel.
