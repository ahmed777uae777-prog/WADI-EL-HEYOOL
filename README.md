# منصة المعلّم الذكية

Cloudflare Worker يقدّم الصفحة (`public/index.html`) كملف ثابت، ويقدّم `/api/doc` لتخزين البيانات في قاعدة D1 (`school-db`).

- `src/worker.js` — نقطة الدخول: حماية بكلمة مرور + توجيه الطلبات.
- `functions/api/doc.js` — منطق القراءة/الكتابة في D1.
- `schema.sql` — جدول `docs`.

## النشر
مربوط بـ Cloudflare Workers Builds: أي `push` إلى `main` يُنشر تلقائيًا (`npx wrangler deploy`).

## الحماية
- تسجيل الدخول يتحقق منه السيرفر (`/api/login`) ويفتح جلسة بكوكي HttpOnly. بدون جلسة لا تُقرأ أي بيانات (`/api/doc` يعيد 401).
- كلمات المرور تُحفظ مشفّرة (HMAC-SHA256 بملح لكل حساب ومفتاح سري في جدول `sys`) ولا تُرسل للمتصفح أبدًا.
- المعلم لا يستطيع تعديل: المعلمين، الطلاب، الجدول، الإعدادات، بيانات المدرسة. يكتب فقط: الغياب، الاحتياط، غياب الطلاب، حجوزات مركز المصادر، السجل.
- قفل مؤقت ١٥ دقيقة بعد ٥ محاولات دخول خاطئة (لكل اسم مستخدم ولكل عنوان IP).
- اختياري: Secret باسم `SITE_PASSWORD` يضع كلمة مرور عامة إضافية على الموقع كله.

## استيراد البيانات الحالية
ملف `seed/seed.sql` خارج Git عمدًا (أسماء وأرقام طلاب). يُستورد من Console قاعدة `school-db` أو:
`npx wrangler d1 execute school-db --remote --file=seed/seed.sql`
